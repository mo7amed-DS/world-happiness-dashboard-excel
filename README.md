
# World Happiness Dashboard (2015–2019)

Interactive Excel dashboard analyzing global happiness trends and key influencing factors across countries.

## Tools Used
- Excel
- Power Query
- Power Pivot
- DAX
- Pivot Tables
- Data Visualization

## Key Insights
- Denmark had the highest average happiness score.
- GDP and Healthy Life Expectancy showed strong positive correlation with happiness.
- Global happiness slightly increased between 2015 and 2019.
